# 🍚 알밥 스터디
> 알고리즘은 우리의 식사

## 📌 진행 개요

- 백준에서 문제집 **[IT기업 및 대기업 계열사 코테보면서 비슷했던 문제들](https://www.acmicpc.net/problem/23971)** 을 풀이한다.
- 언어는 본인이 선호하는 언어로 진행한다.
  - ex) Python, Kotlin 등
- 본인의 닉네임으로 브랜치명을 짓는다.
  - ex) `gong-baek`

## 🗓️ 진행 방식

- 자유롭게 여유가 될 때마다 한 문제씩 진행한다.
